# Pause v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build "Pause", a local-only native Android app that walks the user through a price-scaled smart-spending checklist before a purchase. Ship it as a sideloadable app that Astute Repo (https://github.com/wkubenka/astute-apps) can discover, install and update.

**Architecture:** A single-Activity Jetpack Compose app using MVVM, Hilt, Room and WorkManager, laid out like the other Astute apps (`com.astute.<app>`, `data/ domain/ ui/ di/`). Pure rules (money parsing, tier resolution, warning evaluation, countdowns) live in `domain/` and have plain JVM tests. Persistence and state transitions live in `PurchaseRepository` and `ConfigRepository`, tested against an in-memory Room database under Robolectric. Reminders go through a `ReminderScheduler` interface backed by unique one-time WorkManager jobs. A single `ReminderWorker` re-checks item state before it notifies. Releases are tag-driven GitHub Actions builds that attach one signed APK to a GitHub Release, which is the format Astute Repo reads.

**Tech Stack:** Kotlin 2.2.10, AGP 8.10.0, Gradle 8.11.1, JDK 17, Compose BOM 2026.01.01 + Material 3, Navigation Compose 2.9 (type-safe routes), Hilt 2.58 (+ androidx.hilt 1.3.0 for workers), Room 2.8.4 (KSP 2.3.0), WorkManager 2.10, DataStore Preferences 1.1, kotlinx.serialization 1.9. Tests use JUnit 4, Robolectric 4.14.1, kotlinx-coroutines-test, Turbine and work-testing.

**Spec:** `spec.md` (repo root). Astute Repo's contract is in https://github.com/wkubenka/astute-apps/blob/main/README.md, under "Adding Your App".

## Global Constraints

- Package / applicationId / namespace: `com.astute.pause`. Astute Repo display name: `Astute Pause`. Launcher label: `Pause`.
- `minSdk = 26`, `compileSdk = 36`, `targetSdk = 36`, Java/Kotlin target 17.
- `versionName` and `versionCode` come only from Gradle properties `-PVERSION_NAME` / `-PVERSION_CODE` (defaults `0.1.0` / `1`). Tags are `vX.Y.Z`, and versionCode = `X*10000 + Y*100 + Z` (`v1.2.3` → `10203`). Astute Repo compares the tag (minus `v`) against the installed `versionName`, so they must match exactly.
- Every GitHub Release must have **exactly one** `.apk` asset, signed with the **same keystore every time**, using repo secrets `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS` and `KEY_PASSWORD`. A changed key breaks in-place updates.
- App icon PNG committed at `app/src/main/res/mipmap-xxxhdpi/ic_launcher.png` on `main` (Astute Repo loads it by raw URL).
- GitHub repo `wkubenka/pause` must stay **public**, because Astute Repo calls the unauthenticated releases API.
- Local-only: **no `INTERNET` permission**, no accounts, no sync, no analytics SDKs.
- Money is stored as `Long` cents plus an ISO currency code. Never use `Double` for money.
- The wait runs from `firstConsideredAt`, not from when the questions were finished. It is advisory, never a lock: Bought/Skipped are always available, and buying early is recorded (`decidedAt < waitUntil`).
- No verdict anywhere. The app never recommends Buy, Wait or Skip. Copy stays gentle, using "Not now doesn't have to mean never." No streaks, no guilt.
- Decide notification text is exactly `Still want the <item name>?`.
- Seeded question text is verbatim from *The Smart Spending Checklist* by Sunny Kind Journey (personal use only). Credit the source on the Questions settings screen.
- java.time APIs must exist on API 26 (no `Duration.isPositive`, `toHoursPart`, and so on). There is no core-library desugaring.

## Review Focus

1. **Typed prices with symbols, grouping or a decimal comma** (`$1,299.99`, `1,299`, `12,50`, `1.299,99`, `1e5`). These parse to the correct cents or are rejected with a message. They are never silently scaled 100× or misread. Tests are in Task 3.
2. **An item resumed after its wait already elapsed** (considered Monday, answered Friday, 3-day tier). The summary must not offer "Start the wait" or schedule a reminder in the past. It says the wait is over and offers Bought/Skipped. Tests are in Task 12.
3. **A reminder fires for an item that was decided or deleted in the meantime** (bought early, skipped, discarded). No notification is shown. Tests are in Task 8.
4. **Questions or tiers edited, archived or deleted after items were answered.** History still shows the question text and tier name as they were at answer time. Tests are in Tasks 6 and 15.
5. **Double taps and process death mid-flow.** Tapping Bought twice records one decision and schedules one follow-up. Reopening an in-progress item resumes at the first unanswered question with earlier answers intact. Tests are in Tasks 6 and 11.

```markdown
## Project

Pause (`com.astute.pause`): a local-only Android app that runs a price-scaled smart-spending checklist before non-essential purchases. Spec: `spec.md`. APK=app/build/outputs/apk/release/app-release.apk
```

```bash
"$BUILD_TOOLS/apksigner" verify "$APK"
BADGING=$("$BUILD_TOOLS/aapt2" dump badging "$APK" | head -1)

echo "$BADGING" | grep -q "name='com.astute.pause'"
echo "$BADGING" | grep -q "versionCode='10203'"
echo "$BADGING" | grep -q "versionName='1.2.3'"
if "$BUILD_TOOLS/aapt2" dump permissions "$APK" | grep -q 'android.permission.INTERNET'; then
  echo "INTERNET permission must not be present"; exit 1
fi
echo "OK: release APK is Astute Repo compatible"
```

```kotlin
package com.astute.pause.domain

import java.math.BigDecimal
import java.text.NumberFormat
import java.util.Currency
import java.util.Locale

object Money {
    /** $100,000,000.00. Guards against typos and keeps sums far from Long overflow. */
    const val MAX_CENTS = 10_000_000_000L

    private val PLAIN = Regex("""^(\d+(\.\d{0,2})?|\.\d{1,2})$""")
    private val GROUPED = Regex("""^\d{1,3}(,\d{3})+(\.\d{0,2})?$""")
    private val DECIMAL_COMMA = Regex("""^\d+,\d{1,2}$""")

    fun parseToCents(input: String): Long? {
        val s = input.trim().removePrefix("$").trim()
        val normalized = when {
            PLAIN.matches(s) -> s
            GROUPED.matches(s) -> s.replace(",", "")
            DECIMAL_COMMA.matches(s) -> s.replace(',', '.')
            else -> return null
        }
        val cents = runCatching { BigDecimal(normalized).movePointRight(2).longValueExact() }
            .getOrNull() ?: return null
        return cents.takeIf { it in 0..MAX_CENTS }
    }

    fun format(cents: Long, currencyCode: String, locale: Locale = Locale.getDefault()): String {
        val format = NumberFormat.getCurrencyInstance(locale)
        runCatching { format.currency = Currency.getInstance(currencyCode) }
        return format.format(BigDecimal.valueOf(cents, 2))
    }

    fun toInput(cents: Long): String = BigDecimal.valueOf(cents, 2).toPlainString()

    fun defaultCurrency(locale: Locale = Locale.getDefault()): String =
        runCatching { Currency.getInstance(locale).currencyCode }.getOrDefault("USD")
}
```

**Design decisions recorded here (they deviate slightly from spec §6):**
- `flagged` lives on `Answer`, not `Item`. The spec describes it as per free-text answer. For yes/no and choice answers it is computed from `warningAnswers` when the answer is saved. For text answers the user toggles it.
- `Answer` snapshots `questionText` and `answerType` so History survives question edits (Review Focus #4). Questions are archived (`active = false`), never deleted.
- `Tier` stores only `minCents`. A tier's upper bound is the next tier's minimum minus one cent, so ranges can't overlap or leave gaps. `Tier.name` is added because the spec's table names tiers. `Item.tierName` snapshots it.
- `Question.inRecheck` tags the re-check set. `Tier.questionIds` is the short-list set.

```kotlin
    /** The tier with the highest minimum that the price reaches. Null if no tier starts low enough. */
    fun resolve(tiers: List<Tier>, cents: Long): Tier? =
        tiers.sortedWith(order).lastOrNull { it.minCents <= cents }

    fun waitUntil(firstConsideredAt: Instant, tier: Tier?): Instant? =
        tier?.waitHours?.takeIf { it > 0 }?.let { firstConsideredAt.plus(Duration.ofHours(it.toLong())) }

    fun initialQuestions(tier: Tier?, all: List<Question>): List<Question> {
        val active = all.filter { it.active }.sortedBy { it.sortOrder }
        return if (tier == null || tier.mode == TierMode.FULL) active
        else active.filter { it.id in tier.questionIds }
    }

    fun recheckQuestions(all: List<Question>): List<Question> =
        all.filter { it.active && it.inRecheck }.sortedBy { it.sortOrder }

    fun describeRange(tiers: List<Tier>, tier: Tier, currency: String, locale: Locale = Locale.getDefault()): String {
        val sorted = tiers.sortedWith(order)
        val next = sorted.getOrNull(sorted.indexOfFirst { it.id == tier.id } + 1)
        val fmt = { cents: Long -> Money.format(cents, currency, locale) }
        return when {
            next == null -> "${fmt(tier.minCents)} and up"
            tier.minCents == 0L -> "Under ${fmt(next.minCents)}"
            else -> "${fmt(tier.minCents)} – ${fmt(next.minCents - 1)}"
        }
    }
}
```

```kotlin
package com.astute.pause.domain

import java.time.Duration
import java.time.Instant
import java.time.ZoneId
import java.time.format.DateTimeFormatter
import java.util.Locale

object Countdown {
    fun describe(now: Instant, until: Instant): String {
        val remaining = Duration.between(now, until)
        if (remaining.isNegative || remaining.isZero) return "Ready to decide"
        val days = remaining.toDays()
        val hours = remaining.minusDays(days).toHours()
        val minutes = remaining.toMinutes() % 60
        return when {
            days > 0 -> "${days}d ${hours}h left"
            hours > 0 -> "${hours}h ${minutes}m left"
            else -> "${maxOf(minutes, 1)}m left"
        }
    }

    fun decideOn(at: Instant, zone: ZoneId, locale: Locale = Locale.getDefault()): String =
        DateTimeFormatter.ofPattern("EEE, MMM d 'at' h:mm a", locale).format(at.atZone(zone))

    fun waitLength(hours: Int): String = when {
        hours <= 0 -> "No wait"
        hours % 24 == 0 -> plural(hours / 24, "day")
        else -> plural(hours, "hour")
    }

    private fun plural(n: Int, unit: String) = if (n == 1) "1 $unit" else "$n ${unit}s"
}
```

```kotlin
package com.astute.pause.data.repository

import androidx.room.withTransaction
import com.astute.pause.data.local.PauseDatabase
import com.astute.pause.data.local.entity.Answer
import com.astute.pause.data.local.entity.AnswerPhase
import com.astute.pause.data.local.entity.AnswerType

import com.astute.pause.data.local.entity.Item
import com.astute.pause.data.local.entity.ItemStatus
import com.astute.pause.data.local.entity.Question
import com.astute.pause.domain.AnswerEvaluator
import com.astute.pause.domain.Money
import com.astute.pause.domain.TierResolver
import com.astute.pause.reminders.ReminderScheduler
import kotlinx.coroutines.flow.Flow
import java.time.Clock
import java.time.Duration
import java.time.Instant
import javax.inject.Inject
import javax.inject.Singleton

@Singleton
class PurchaseRepository @Inject constructor(
    private val db: PauseDatabase,
    private val scheduler: ReminderScheduler,
    private val clock: Clock,
) {
    private val items = db.itemDao()
    private val answers = db.answerDao()
    private val questions = db.questionDao()
    private val tiers = db.tierDao()

    suspend fun startItem(name: String, currency: String = Money.defaultCurrency()): Long {
        val trimmed = name.trim()
        require(trimmed.isNotEmpty()) { "Item name is blank" }
        return items.insert(
            Item(name = trimmed, firstConsideredAt = clock.instant(), currency = currency, status = ItemStatus.CONSIDERING)
        )
    }

    suspend fun item(id: Long): Item? = items.get(id)
    fun observeItem(id: Long): Flow<Item?> = items.observe(id)

    suspend fun setCost(itemId: Long, cents: Long, notes: String? = null) {
        val item = items.get(itemId) ?: return
        val tier = TierResolver.resolve(tiers.all(), cents)
        items.update(
            item.copy(
                costCents = cents,
                notes = notes?.trim() ?: item.notes,
                tierId = tier?.id,
                tierName = tier?.name,
                waitUntil = TierResolver.waitUntil(item.firstConsideredAt, tier),
            )
        )
    }

    suspend fun questionsFor(itemId: Long, phase: AnswerPhase): List<Question> {
        val all = questions.all()
        return when (phase) {
            AnswerPhase.RECHECK -> TierResolver.recheckQuestions(all)
            AnswerPhase.INITIAL -> {
                val tier = items.get(itemId)?.tierId?.let { tiers.get(it) }
                TierResolver.initialQuestions(tier, all)
            }
        }
    }

    suspend fun saveAnswer(itemId: Long, question: Question, answer: String, note: String, phase: AnswerPhase) {
        db.withTransaction {
            val existing = answers.find(itemId, question.id, phase)
            val flagged = if (question.answerType == AnswerType.TEXT) existing?.flagged ?: false
            else AnswerEvaluator.isWarning(question, answer)
            val row = Answer(
                id = existing?.id ?: 0,
                itemId = itemId,
                questionId = question.id,
                questionText = question.text,
                answerType = question.answerType,
                answer = answer.trim(),
                note = note.trim(),
                answeredAt = clock.instant(),
                phase = phase,
                flagged = flagged,
            )
            if (existing == null) answers.insert(row) else answers.update(row)
        }
    }

    fun observeAnswers(itemId: Long, phase: AnswerPhase): Flow<List<Answer>> = answers.observeForItem(itemId, phase)
    suspend fun answersFor(itemId: Long, phase: AnswerPhase): List<Answer> = answers.forItem(itemId, phase)
    suspend fun setFlagged(answerId: Long, flagged: Boolean) = answers.setFlagged(answerId, flagged)

    suspend fun startWaiting(itemId: Long): Boolean {
        val item = items.get(itemId) ?: return false
        val until = item.waitUntil ?: return false
        if (item.status != ItemStatus.CONSIDERING) return false
        items.update(item.copy(status = ItemStatus.WAITING))
        scheduler.scheduleDecide(itemId, until)
        return true
    }

    suspend fun markBought(itemId: Long, finalCents: Long): Boolean {
        val item = items.get(itemId) ?: return false
        if (item.status !in OPEN) return false
        val now = clock.instant()
        val due = now.plus(FOLLOW_UP_DELAY)
        items.update(item.copy(status = ItemStatus.BOUGHT, decidedAt = now, finalCostCents = finalCents, followupDueAt = due))
        scheduler.cancelDecide(itemId)
        scheduler.scheduleFollowUp(itemId, due)
        return true
    }

    suspend fun markSkipped(itemId: Long): Boolean {
        val item = items.get(itemId) ?: return false
        if (item.status !in OPEN) return false
        items.update(item.copy(status = ItemStatus.SKIPPED, decidedAt = clock.instant()))
        scheduler.cancelDecide(itemId)
        return true
    }

    suspend fun answerFollowUp(itemId: Long, remembersIt: Boolean, happyWithIt: Boolean): Boolean {
        val item = items.get(itemId) ?: return false
        if (item.status != ItemStatus.BOUGHT || item.followupAnsweredAt != null) return false
        items.update(item.copy(remembersIt = remembersIt, happyWithIt = happyWithIt, followupAnsweredAt = clock.instant()))
        return true
    }

    suspend fun deleteItem(itemId: Long) {
        items.delete(itemId)
        scheduler.cancelAll(itemId)
    }

    fun observeInProgress(): Flow<List<Item>> = items.observeInProgress()
    fun observeWaiting(): Flow<List<Item>> = items.observeWaiting()
    fun observeDecided(): Flow<List<Item>> = items.observeDecided()
    fun observeFollowUpsDue(now: Instant): Flow<List<Item>> = items.observeFollowUpsDue(now)
    fun observeSkippedTotals(): Flow<List<CurrencyTotal>> = items.observeSkippedTotals()

    companion object {
        val FOLLOW_UP_DELAY: Duration = Duration.ofDays(90)
        private val OPEN = setOf(ItemStatus.CONSIDERING, ItemStatus.WAITING)
    }
}
```

```kotlin
package com.astute.pause.data.repository

import androidx.room.withTransaction
import com.astute.pause.data.local.PauseDatabase
import com.astute.pause.data.local.SeedData
import com.astute.pause.data.local.entity.AnswerType
import com.astute.pause.data.local.entity.Question
import com.astute.pause.data.local.entity.Tier

import javax.inject.Inject
import javax.inject.Singleton

@Singleton
class ConfigRepository @Inject constructor(private val db: PauseDatabase) {
    private val tierDao = db.tierDao()
    private val questionDao = db.questionDao()

    fun observeTiers(): Flow<List<Tier>> = tierDao.observeAll()
    suspend fun tiers(): List<Tier> = tierDao.all()
    suspend fun tier(id: Long): Tier? = tierDao.get(id)

    suspend fun saveTier(tier: Tier): Long {
        val clean = tier.copy(name = tier.name.trim())
        return if (clean.id == 0L) tierDao.insert(clean) else clean.id.also { tierDao.update(clean) }
    }

    suspend fun deleteTier(tier: Tier) = tierDao.delete(tier)

    fun observeQuestions(): Flow<List<Question>> = questionDao.observeAll()
    suspend fun questions(): List<Question> = questionDao.all()
    suspend fun question(id: Long): Question? = questionDao.get(id)

    suspend fun saveQuestion(question: Question): Long = db.withTransaction {
        val clean = sanitize(question)
        if (clean.id == 0L) questionDao.insert(clean.copy(sortOrder = questionDao.maxSortOrder() + 1))
        else clean.id.also { questionDao.update(clean) }
    }

    suspend fun move(questionId: Long, up: Boolean) {
        db.withTransaction {
            val all = questionDao.all()
            val i = all.indexOfFirst { it.id == questionId }
            val j = if (up) i - 1 else i + 1
            if (i < 0 || j !in all.indices) return@withTransaction
            val a = all[i]
            val b = all[j]
            questionDao.updateAll(listOf(a.copy(sortOrder = b.sortOrder), b.copy(sortOrder = a.sortOrder)))
        }
    }

    suspend fun setActive(questionId: Long, active: Boolean) {
        val q = questionDao.get(questionId) ?: return
        questionDao.update(q.copy(active = active))
    }

    private fun sanitize(q: Question): Question {
        val options = if (q.answerType == AnswerType.CHOICE) q.options.map { it.trim() }.filter { it.isNotEmpty() }.distinct()
        else emptyList()
        val valid = when (q.answerType) {
            AnswerType.YES_NO -> listOf(SeedData.YES, SeedData.NO)
            AnswerType.CHOICE -> options
            AnswerType.TEXT -> emptyList()
        }
        return q.copy(text = q.text.trim(), options = options, warningAnswers = q.warningAnswers.filter { it in valid }.distinct())
    }
}
```

```kotlin
package com.astute.pause.reminders

import android.content.Intent

sealed interface DeepLinkTarget {
    data class Recheck(val itemId: Long) : DeepLinkTarget
    data class FollowUp(val itemId: Long) : DeepLinkTarget
}

object DeepLink {
    const val EXTRA_ITEM_ID = "com.astute.pause.ITEM_ID"
    const val EXTRA_TARGET = "com.astute.pause.TARGET"
    const val TARGET_RECHECK = "recheck"
    const val TARGET_FOLLOWUP = "followup"

    fun parse(intent: Intent?): DeepLinkTarget? {
        if (intent == null) return null
        val itemId = intent.getLongExtra(EXTRA_ITEM_ID, -1L).takeIf { it > 0 } ?: return null
        return when (intent.getStringExtra(EXTRA_TARGET)) {
            TARGET_RECHECK -> DeepLinkTarget.Recheck(itemId)
            TARGET_FOLLOWUP -> DeepLinkTarget.FollowUp(itemId)
            else -> null
        }
    }
}
```

```kotlin
package com.astute.pause.reminders

import android.Manifest
import android.app.NotificationChannel
import android.app.NotificationManager
import android.app.PendingIntent
import android.content.Context
import android.content.Intent
import android.content.pm.PackageManager
import android.os.Build
import androidx.core.app.NotificationCompat
import androidx.core.app.NotificationManagerCompat
import androidx.core.content.ContextCompat
import com.astute.pause.MainActivity
import com.astute.pause.R
import dagger.hilt.android.qualifiers.ApplicationContext
import javax.inject.Inject
import javax.inject.Singleton

sealed interface PauseNotification {
    val itemId: Long
    val itemName: String

    data class Decide(override val itemId: Long, override val itemName: String) : PauseNotification
    data class Nudge(override val itemId: Long, override val itemName: String) : PauseNotification
    data class FollowUp(override val itemId: Long, override val itemName: String) : PauseNotification
}

interface Notifier {
    fun show(notification: PauseNotification)
}

@Singleton
class AndroidNotifier @Inject constructor(
    @ApplicationContext private val context: Context,
) : Notifier {

    override fun show(notification: PauseNotification) {
        if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.TIRAMISU &&
            ContextCompat.checkSelfPermission(context, Manifest.permission.POST_NOTIFICATIONS) != PackageManager.PERMISSION_GRANTED
        ) return
        createChannels()

        val (channel, title, text, target, slot) = when (notification) {
            is PauseNotification.Decide -> Spec(
                CHANNEL_DECIDE, "Still want the ${notification.itemName}?",
                "Your wait is over. Take a look whenever you're ready.", DeepLink.TARGET_RECHECK, 0,
            )
            is PauseNotification.Nudge -> Spec(
                CHANNEL_DECIDE, "${notification.itemName} is still here",
                "No rush. Not now doesn't have to mean never.", DeepLink.TARGET_RECHECK, 1,
            )
            is PauseNotification.FollowUp -> Spec(
                CHANNEL_FOLLOWUP, "Looking back at ${notification.itemName}",
                "Two quick questions about something you bought 90 days ago.", DeepLink.TARGET_FOLLOWUP, 2,
            )
        }
        val requestCode = (notification.itemId * 3 + slot).toInt()
        val intent = Intent(context, MainActivity::class.java).apply {
            flags = Intent.FLAG_ACTIVITY_SINGLE_TOP or Intent.FLAG_ACTIVITY_CLEAR_TOP
            putExtra(DeepLink.EXTRA_ITEM_ID, notification.itemId)
            putExtra(DeepLink.EXTRA_TARGET, target)
        }
        val pending = PendingIntent.getActivity(
            context, requestCode, intent, PendingIntent.FLAG_IMMUTABLE or PendingIntent.FLAG_UPDATE_CURRENT,
        )
        val built = NotificationCompat.Builder(context, channel)
            .setSmallIcon(R.drawable.ic_launcher_foreground)
            .setContentTitle(title)
            .setContentText(text)
            .setContentIntent(pending)
            .setAutoCancel(true)
            .build()
        NotificationManagerCompat.from(context).notify(requestCode, built)
    }

    private data class Spec(val channel: String, val title: String, val text: String, val target: String, val slot: Int)

    private fun createChannels() {
        val manager = context.getSystemService(NotificationManager::class.java)
```

```kotlin
package com.astute.pause.reminders

import com.astute.pause.data.local.entity.ItemStatus
import com.astute.pause.data.repository.PurchaseRepository
import com.astute.pause.data.settings.NotificationSettings
import kotlinx.coroutines.flow.first
import java.time.Clock
import java.time.Duration
import javax.inject.Inject

/** Worker-side logic. Every action re-reads the item so stale reminders stay silent. */
class ReminderActions @Inject constructor(
    private val repo: PurchaseRepository,
    private val settings: NotificationSettings,
    private val notifier: Notifier,
    private val scheduler: ReminderScheduler,
    private val clock: Clock,
) {
    suspend fun onDecideDue(itemId: Long) {
        val item = repo.item(itemId) ?: return
        if (item.status != ItemStatus.WAITING) return
        val config = settings.config.first()
        if (config.remindersEnabled) notifier.show(PauseNotification.Decide(item.id, item.name))
        if (config.nudgeEnabled) scheduler.scheduleNudge(item.id, clock.instant().plus(NUDGE_AFTER))
    }

    suspend fun onNudgeDue(itemId: Long) {
        val item = repo.item(itemId) ?: return
        if (item.status != ItemStatus.WAITING) return
        if (settings.config.first().nudgeEnabled) notifier.show(PauseNotification.Nudge(item.id, item.name))
    }

    suspend fun onFollowUpDue(itemId: Long) {
        val item = repo.item(itemId) ?: return
        if (item.status != ItemStatus.BOUGHT || item.followupAnsweredAt != null) return
        if (settings.config.first().followUpEnabled) notifier.show(PauseNotification.FollowUp(item.id, item.name))
    }

    private companion object {
        val NUDGE_AFTER: Duration = Duration.ofDays(1)
    }
}
```

`reminders/ReminderWorker.kt`:
```kotlin
package com.astute.pause.reminders

import android.content.Context
import androidx.hilt.work.HiltWorker
import androidx.work.CoroutineWorker
import androidx.work.WorkerParameters
import dagger.assisted.Assisted
import dagger.assisted.AssistedInject

@HiltWorker
class ReminderWorker @AssistedInject constructor(
    @Assisted context: Context,
    @Assisted params: WorkerParameters,
    private val actions: ReminderActions,
) : CoroutineWorker(context, params) {

    override suspend fun doWork(): Result {
        val itemId = inputData.getLong(KEY_ITEM_ID, -1L)
        if (itemId <= 0) return Result.failure()
        when (inputData.getString(KEY_KIND)) {
            KIND_DECIDE -> actions.onDecideDue(itemId)
            KIND_NUDGE -> actions.onNudgeDue(itemId)
            KIND_FOLLOWUP -> actions.onFollowUpDue(itemId)
            else -> return Result.failure()
        }
        return Result.success()
    }

    companion object {
        const val KEY_ITEM_ID = "item_id"
        const val KEY_KIND = "kind"
        const val KIND_DECIDE = "decide"
        const val KIND_NUDGE = "nudge"
        const val KIND_FOLLOWUP = "followup"
    }
}
```

```kotlin
package com.astute.pause.reminders

import androidx.work.ExistingWorkPolicy
import androidx.work.OneTimeWorkRequestBuilder
import androidx.work.WorkManager
import androidx.work.workDataOf
import java.time.Clock
import java.time.Duration
import java.time.Instant
import java.util.concurrent.TimeUnit
import javax.inject.Inject
import javax.inject.Singleton

@Singleton
class WorkManagerReminderScheduler @Inject constructor(
    private val workManager: WorkManager,
    private val clock: Clock,
) : ReminderScheduler {

    override fun scheduleDecide(itemId: Long, at: Instant) = enqueue(ReminderWorker.KIND_DECIDE, itemId, at)
    override fun scheduleNudge(itemId: Long, at: Instant) = enqueue(ReminderWorker.KIND_NUDGE, itemId, at)
    override fun scheduleFollowUp(itemId: Long, at: Instant) = enqueue(ReminderWorker.KIND_FOLLOWUP, itemId, at)

    override fun cancelDecide(itemId: Long) {
        workManager.cancelUniqueWork(workName(ReminderWorker.KIND_DECIDE, itemId))
        workManager.cancelUniqueWork(workName(ReminderWorker.KIND_NUDGE, itemId))
    }

    override fun cancelAll(itemId: Long) {
        cancelDecide(itemId)
        workManager.cancelUniqueWork(workName(ReminderWorker.KIND_FOLLOWUP, itemId))
    }

    private fun enqueue(kind: String, itemId: Long, at: Instant) {
        val delayMillis = Duration.between(clock.instant(), at).toMillis().coerceAtLeast(0)
        val request = OneTimeWorkRequestBuilder<ReminderWorker>()
            .setInitialDelay(delayMillis, TimeUnit.MILLISECONDS)
            .setInputData(workDataOf(ReminderWorker.KEY_ITEM_ID to itemId, ReminderWorker.KEY_KIND to kind))
            .build()
        workManager.enqueueUniqueWork(workName(kind, itemId), ExistingWorkPolicy.REPLACE, request)
    }

    companion object {
        fun workName(kind: String, itemId: Long) = "$kind-$itemId"
    }
}
```

```kotlin
data class CostState(

    val input: String = "",

    val error: String? = null,

    private val config: ConfigRepository,
    private val clock: Clock,

    val state: StateFlow<CostState> = _state.asStateFlow()

    private var item: Item? = null
    private var tiers: List<Tier> = emptyList()
    private var questions: List<Question> = emptyList()

    init {
        viewModelScope.launch {
            item = repo.item(itemId)
            tiers = config.tiers()
            questions = config.questions()
            val current = item
            val input = current?.costCents?.let(Money::toInput) ?: ""
            _state.value = CostState(
                loading = false,
                itemName = current?.name.orEmpty(),
                input = input,
                notes = current?.notes.orEmpty(),
                preview = preview(input),
            )
        }
    }

    fun setInput(value: String) = _state.update { it.copy(input = value, preview = preview(value), error = null) }
    fun setNotes(value: String) = _state.update { it.copy(notes = value) }

    fun submit(onDone: () -> Unit) {
        val cents = Money.parseToCents(_state.value.input)
        if (cents == null) {
            _state.update { it.copy(error = "Enter the full price as a number, like 49.99.") }
            return
        }
        viewModelScope.launch {
            repo.setCost(itemId, cents, _state.value.notes)
            onDone()
        }
    }

    private fun preview(input: String): TierPreview? {
        val cents = Money.parseToCents(input) ?: return null
        val first = item?.firstConsideredAt ?: return null
        val tier = TierResolver.resolve(tiers, cents)
        val until = TierResolver.waitUntil(first, tier)
        return TierPreview(
            tierName = tier?.name,
            questionCount = TierResolver.initialQuestions(tier, questions).size,
            waitLabel = Countdown.waitLength(tier?.waitHours ?: 0),
            decideOn = until?.let { Countdown.decideOn(it, clock.zone) },
        )
    }
}
```

```kotlin
import androidx.lifecycle.SavedStateHandle
import androidx.lifecycle.ViewModel

import com.astute.pause.data.local.entity.AnswerPhase

import com.astute.pause.data.local.entity.ItemStatus
import com.astute.pause.data.local.entity.Question
import com.astute.pause.data.repository.PurchaseRepository
import dagger.hilt.android.lifecycle.HiltViewModel
import kotlinx.coroutines.flow.MutableStateFlow
import kotlinx.coroutines.flow.StateFlow
import kotlinx.coroutines.flow.asStateFlow
import kotlinx.coroutines.launch
import javax.inject.Inject

data class WalkthroughState(
    val loading: Boolean = true,
    val itemName: String = "",
    val questions: List<Question> = emptyList(),
    val index: Int = 0,
    val answer: String = "",
    val note: String = "",
    val finished: Boolean = false,
    val alreadyDecided: Boolean = false,
) {
    val current: Question? get() = questions.getOrNull(index)
    val canContinue: Boolean get() = current?.let { it.answerType == AnswerType.TEXT || answer.isNotBlank() } ?: false
    val progress: Float get() = if (questions.isEmpty()) 1f else (index + 1f) / questions.size
}

@HiltViewModel
class WalkthroughViewModel @Inject constructor(
    savedStateHandle: SavedStateHandle,
    private val repo: PurchaseRepository,
) : ViewModel() {
    private val itemId: Long = checkNotNull(savedStateHandle["itemId"])
    private val phase = if (savedStateHandle.get<Boolean>("recheck") == true) AnswerPhase.RECHECK else AnswerPhase.INITIAL
    private val drafts = mutableMapOf<Long, Pair<String, String>>()

    private val _state = MutableStateFlow(WalkthroughState())
    val state: StateFlow<WalkthroughState> = _state.asStateFlow()

    init {
        viewModelScope.launch {
            val item = repo.item(itemId)
            if (item == null || item.status == ItemStatus.BOUGHT || item.status == ItemStatus.SKIPPED) {
                _state.value = WalkthroughState(loading = false, itemName = item?.name.orEmpty(), alreadyDecided = true)
                return@launch
            }
            val questions = repo.questionsFor(itemId, phase)
            repo.answersFor(itemId, phase).forEach { drafts[it.questionId] = it.answer to it.note }
            val start = questions.indexOfFirst { it.id !in drafts }.takeIf { it >= 0 } ?: 0
            _state.value = WalkthroughState(
                loading = false, itemName = item.name, questions = questions, index = start,
                finished = questions.isEmpty(),
            ).withDraft()
        }
    }

    fun setAnswer(value: String) = edit { it.copy(answer = value) }
    fun setNote(value: String) = edit { it.copy(note = value) }

    fun next() {
        val s = _state.value
        val q = s.current ?: return
        if (!s.canContinue) return
        viewModelScope.launch {
            repo.saveAnswer(itemId, q, s.answer, s.note, phase)
            val nextIndex = s.index + 1
            _state.value = if (nextIndex >= s.questions.size) s.copy(finished = true)
            else s.copy(index = nextIndex).withDraft()
        }
    }

    fun back(): Boolean {
        val s = _state.value
        if (s.index == 0) return false
        _state.value = s.copy(index = s.index - 1).withDraft()
        return true
    }

    private fun edit(transform: (WalkthroughState) -> WalkthroughState) {
        val next = transform(_state.value)
        next.current?.let { drafts[it.id] = next.answer to next.note }
        _state.value = next
    }

    private fun WalkthroughState.withDraft(): WalkthroughState {
        val q = current ?: return this
        val (answer, note) = drafts[q.id] ?: ("" to "")
        return copy(answer = answer, note = note)
    }
}
```

```kotlin
import com.astute.pause.data.repository.PurchaseRepository
import com.astute.pause.domain.Countdown
import com.astute.pause.domain.Money
import dagger.hilt.android.lifecycle.HiltViewModel
import kotlinx.coroutines.flow.MutableStateFlow
import kotlinx.coroutines.flow.SharingStarted
import kotlinx.coroutines.flow.StateFlow
import kotlinx.coroutines.flow.combine
import kotlinx.coroutines.flow.stateIn
import kotlinx.coroutines.launch
import java.time.Clock
import java.time.Instant
import javax.inject.Inject

data class SummaryState(
    val item: Item? = null,
    val answers: List<Answer> = emptyList(),
    val recheck: Boolean = false,
    val now: Instant = Instant.EPOCH,
    val decideOn: String? = null,
    val error: String? = null,
) {
    val warningCount: Int get() = answers.count { it.flagged }
    val isOpen: Boolean get() = item?.status == ItemStatus.CONSIDERING || item?.status == ItemStatus.WAITING

    val canStartWait: Boolean
        get() {
            val i = item ?: return false
            val until = i.waitUntil ?: return false
            return !recheck && i.status == ItemStatus.CONSIDERING && until.isAfter(now)
        }

    val waitAlreadyOver: Boolean
        get() {
            val until = item?.waitUntil ?: return false
            return !until.isAfter(now)
        }
}

@HiltViewModel
class SummaryViewModel @Inject constructor(
    savedStateHandle: SavedStateHandle,
    private val repo: PurchaseRepository,
    private val clock: Clock,
) : ViewModel() {
    private val itemId: Long = checkNotNull(savedStateHandle["itemId"])
    private val recheck: Boolean = savedStateHandle["recheck"] ?: false
    private val error = MutableStateFlow<String?>(null)

    val state: StateFlow<SummaryState> = combine(
        repo.observeItem(itemId),
        repo.observeAnswers(itemId, if (recheck) AnswerPhase.RECHECK else AnswerPhase.INITIAL),
        error,
    ) { item, answers, err ->
        SummaryState(
            item = item, answers = answers, recheck = recheck, now = clock.instant(),
            decideOn = item?.waitUntil?.let { Countdown.decideOn(it, clock.zone) }, error = err,
        )
    }.stateIn(viewModelScope, SharingStarted.WhileSubscribed(5_000), SummaryState(recheck = recheck))

    fun toggleFlag(answer: Answer) {
        if (answer.answerType != AnswerType.TEXT) return
        viewModelScope.launch { repo.setFlagged(answer.id, !answer.flagged) }
    }

    fun startWaiting(onDone: () -> Unit) {
        viewModelScope.launch { if (repo.startWaiting(itemId)) onDone() }
    }

    fun markBought(finalCostInput: String, onDone: () -> Unit) {
        val cents = Money.parseToCents(finalCostInput)
        if (cents == null) {
            error.value = "Enter what you paid as a number, like 49.99."
            return
        }
        error.value = null
        viewModelScope.launch { repo.markBought(itemId, cents); onDone() }
    }

    fun markSkipped(onDone: () -> Unit) {
        viewModelScope.launch { repo.markSkipped(itemId); onDone() }
    }
}
```

```kotlin
import androidx.lifecycle.SavedStateHandle
import androidx.lifecycle.ViewModel

import com.astute.pause.data.local.entity.Item

import kotlinx.coroutines.flow.SharingStarted

import kotlinx.coroutines.flow.combine

import kotlinx.coroutines.launch
import javax.inject.Inject

data class FollowUpState(val item: Item? = null, val remembers: Boolean? = null, val happy: Boolean? = null) {
    val canSubmit: Boolean get() = remembers != null && happy != null && !alreadyAnswered
    val alreadyAnswered: Boolean get() = item?.followupAnsweredAt != null
}

@HiltViewModel
class FollowUpViewModel @Inject constructor(
    savedStateHandle: SavedStateHandle,
    private val repo: PurchaseRepository,
) : ViewModel() {
    private val itemId: Long = checkNotNull(savedStateHandle["itemId"])
    private val remembers = MutableStateFlow<Boolean?>(null)
    private val happy = MutableStateFlow<Boolean?>(null)

    val state: StateFlow<FollowUpState> = combine(repo.observeItem(itemId), remembers, happy) { item, r, h ->
        FollowUpState(item, r, h)
    }.stateIn(viewModelScope, SharingStarted.Eagerly, FollowUpState())

    fun setRemembers(value: Boolean) { remembers.value = value }
    fun setHappy(value: Boolean) { happy.value = value }

    fun submit(onDone: () -> Unit) {
        val r = remembers.value ?: return
        val h = happy.value ?: return
        viewModelScope.launch { repo.answerFollowUp(itemId, r, h); onDone() }
    }
}
```

```kotlin
package com.astute.pause.ui.settings

import androidx.lifecycle.SavedStateHandle
import androidx.lifecycle.ViewModel
import androidx.lifecycle.viewModelScope
import com.astute.pause.data.local.entity.Question
import com.astute.pause.data.local.entity.Tier

import dagger.hilt.android.lifecycle.HiltViewModel
import kotlinx.coroutines.flow.MutableStateFlow
import kotlinx.coroutines.flow.StateFlow
import kotlinx.coroutines.flow.asStateFlow
import kotlinx.coroutines.flow.update
import kotlinx.coroutines.launch
import javax.inject.Inject

enum class WaitUnit { HOURS, DAYS }

data class TierEditState(
    val loading: Boolean = true,
    val isNew: Boolean = true,
    val name: String = "",
    val minPrice: String = "",
    val mode: TierMode = TierMode.FULL,
    val waitAmount: String = "0",
    val waitUnit: WaitUnit = WaitUnit.DAYS,
    val selectedQuestionIds: Set<Long> = emptySet(),
    val questions: List<Question> = emptyList(),
    val error: String? = null,
)

@HiltViewModel
class TierEditViewModel @Inject constructor(
    savedStateHandle: SavedStateHandle,
    private val config: ConfigRepository,
) : ViewModel() {
    private val tierId: Long = savedStateHandle["tierId"] ?: 0L
    private val _state = MutableStateFlow(TierEditState())
    val state: StateFlow<TierEditState> = _state.asStateFlow()

    init {
        viewModelScope.launch {
            val questions = config.questions().filter { it.active }
            val tier = if (tierId != 0L) config.tier(tierId) else null
            _state.value = if (tier == null) TierEditState(loading = false, questions = questions)
            else {
                val days = tier.waitHours > 0 && tier.waitHours % 24 == 0
                TierEditState(
                    loading = false, isNew = false, name = tier.name, minPrice = Money.toInput(tier.minCents),
                    mode = tier.mode,
                    waitAmount = (if (days) tier.waitHours / 24 else tier.waitHours).toString(),
                    waitUnit = if (days || tier.waitHours == 0) WaitUnit.DAYS else WaitUnit.HOURS,
                    selectedQuestionIds = tier.questionIds.toSet(), questions = questions,
                )
            }
        }
    }

    fun update(transform: (TierEditState) -> TierEditState) = _state.update { transform(it).copy(error = null) }

    fun toggleQuestion(id: Long) = update {
        it.copy(selectedQuestionIds = if (id in it.selectedQuestionIds) it.selectedQuestionIds - id else it.selectedQuestionIds + id)
    }

    fun save(onDone: () -> Unit) {
        val s = _state.value
        val name = s.name.trim()
        if (name.isEmpty()) return fail("Give the tier a name.")
        val minCents = Money.parseToCents(s.minPrice) ?: return fail("Enter the starting price, like 25.")
        val amount = s.waitAmount.trim().ifEmpty { "0" }.toLongOrNull()?.takeIf { it >= 0 }
            ?: return fail("Enter the wait as a whole number.")
        val hours = amount * if (s.waitUnit == WaitUnit.DAYS) 24 else 1
        if (hours > MAX_WAIT_HOURS) return fail("Keep the wait under a year.")
        if (s.mode == TierMode.SHORT && s.selectedQuestionIds.isEmpty()) return fail("Pick at least one question for the short list.")
        viewModelScope.launch {
            if (config.tiers().any { it.id != tierId && it.minCents == minCents }) {
                fail("Another tier already starts at that price.")
                return@launch
            }
            config.saveTier(
                Tier(id = tierId, name = name, minCents = minCents, mode = s.mode, waitHours = hours.toInt(),
                    questionIds = s.selectedQuestionIds.sorted())
            )
            onDone()
        }
    }

    fun delete(onDone: () -> Unit) {
        if (tierId == 0L) return onDone()
        viewModelScope.launch { config.tier(tierId)?.let { config.deleteTier(it) }; onDone() }
    }

    private fun fail(message: String) = _state.update { it.copy(error = message) }

    private companion object {
        const val MAX_WAIT_HOURS = 24L * 366
    }
}
```

```kotlin
package com.astute.pause.ui.questions

import androidx.lifecycle.SavedStateHandle
import androidx.lifecycle.ViewModel
import androidx.lifecycle.viewModelScope
import com.astute.pause.data.local.SeedData
import com.astute.pause.data.local.entity.AnswerType
import com.astute.pause.data.local.entity.Question
import com.astute.pause.data.local.entity.QuestionGroup
import com.astute.pause.data.repository.ConfigRepository
import dagger.hilt.android.lifecycle.HiltViewModel
import kotlinx.coroutines.flow.MutableStateFlow
import kotlinx.coroutines.flow.StateFlow
import kotlinx.coroutines.flow.asStateFlow
import kotlinx.coroutines.flow.update
import kotlinx.coroutines.launch
import javax.inject.Inject

data class QuestionEditState(
    val loading: Boolean = true,
    val isNew: Boolean = true,
    val text: String = "",
    val group: QuestionGroup = QuestionGroup.NEED_CLARITY,
    val answerType: AnswerType = AnswerType.YES_NO,
    val optionsText: String = "",
    val warningAnswers: Set<String> = emptySet(),
    val inRecheck: Boolean = false,
    val active: Boolean = true,
    val sortOrder: Int = 0,
    val error: String? = null,
) {
    val options: List<String> get() = optionsText.lines().map { it.trim() }.filter { it.isNotEmpty() }.distinct()
    val warningChoices: List<String>
        get() = when (answerType) {
            AnswerType.YES_NO -> listOf(SeedData.YES, SeedData.NO)
            AnswerType.CHOICE -> options
            AnswerType.TEXT -> emptyList()
        }
}

@HiltViewModel
class QuestionEditViewModel @Inject constructor(
    savedStateHandle: SavedStateHandle,
    private val config: ConfigRepository,
) : ViewModel() {
    private val questionId: Long = savedStateHandle["questionId"] ?: 0L
    private val _state = MutableStateFlow(QuestionEditState())
    val state: StateFlow<QuestionEditState> = _state.asStateFlow()

    init {
        viewModelScope.launch {
            val q = if (questionId != 0L) config.question(questionId) else null
            _state.value = if (q == null) QuestionEditState(loading = false)
            else QuestionEditState(
                loading = false, isNew = false, text = q.text, group = q.group, answerType = q.answerType,
                optionsText = q.options.joinToString("\n"), warningAnswers = q.warningAnswers.toSet(),
                inRecheck = q.inRecheck, active = q.active, sortOrder = q.sortOrder,
            )
        }
    }

    fun update(transform: (QuestionEditState) -> QuestionEditState) = _state.update { transform(it).copy(error = null) }
    fun setType(type: AnswerType) = update { it.copy(answerType = type, warningAnswers = emptySet()) }
    fun toggleWarning(answer: String) = update {
        it.copy(warningAnswers = if (answer in it.warningAnswers) it.warningAnswers - answer else it.warningAnswers + answer)
    }

    fun save(onDone: () -> Unit) {
        val s = _state.value
        if (s.text.isBlank()) return _state.update { it.copy(error = "Write the question.") }
        if (s.answerType == AnswerType.CHOICE && s.options.size < 2) {
            return _state.update { it.copy(error = "Add at least two choices, one per line.") }
        }
        viewModelScope.launch {
            config.saveQuestion(
                Question(
                    id = questionId, text = s.text, group = s.group, active = s.active, sortOrder = s.sortOrder,
                    answerType = s.answerType, options = s.options,
                    warningAnswers = s.warningAnswers.filter { it in s.warningChoices }, inRecheck = s.inRecheck,
                )
            )
            onDone()
        }
    }
}
```

```markdown
# Pause

A personal Android app that walks you through a smart-spending checklist before non-essential purchases, with scrutiny scaled to the price. Local-only: no accounts, no network.

## How it works

1. Type what you're thinking of buying (the time is recorded).
2. Enter the all-in price; a tier is chosen automatically.
3. Answer the tier's questions, one per screen.
4. Review a summary with warning signs highlighted. The app never tells you what to do.
5. Bigger purchases get an advisory cool-off measured from when you first considered them, with a reminder when it ends.
6. 90 days after buying, two quick look-back questions.

Tiers, questions and notifications are all editable in Settings.
```
